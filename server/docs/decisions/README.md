# Decision Records

## Process

A detailed description of adding new MADRs can be found [here}(https://adr.github.io/madr).

In the following, only a short overview is given:

1. Copy of the templates [adr-template-bare.md](docs\decisions\adr-template-bare.md) or [adr-template.md](docs\decisions\adr-template.md)
2. Rename the file by increasing the number in the filename and set an appropriate title (lowercase with dashes) which reflects the content of the MADR, e.g.: `0023-UI-framework-selection`.
3. Open the file and fill out all required parts of the template / drop parts not required/used
4. Discuss the to be made decision with the team
5. Document the decision outcome within the MADR and apply the decision to the project

## Templates

The templates [adr-template-bare.md](docs\decisions\adr-template-bare.md) and [adr-template.md](docs\decisions\adr-template.md) used within this project are originally provided as part of the respective [MADR GitHub project](https://github.com/adr/madr/).
